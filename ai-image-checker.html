About this AI image checker

Many AI image generators quietly label their output inside the file — in content credentials, EXIF and metadata fields, or hidden text chunks. This free AI image checker inspects those places and reports what it finds. Be clear about its limits: it is a basic check. A fingerprint is strong evidence an image was AI-made, but a clean result does not prove an image is real, because metadata can be stripped. Use it as a first check, not a final verdict.

Frequently asked questions

How can I tell if an image was generated by AI?
This checker reads the image file itself for AI fingerprints — content credentials (C2PA), generator metadata and hidden text chunks left by AI image tools. A fingerprint is strong evidence the image was AI-made; a clean result is not proof an image is real, because metadata can be removed.
What is a C2PA content credential?
Content credentials are a provenance standard that cameras and AI generators use to record where an image came from and how it was made, stored inside the file itself. This checker looks for them.
Can this checker prove an image is real?
No — and it does not claim to. It reports the fingerprints it finds inside the file. No fingerprints means no evidence was found in the file, not a guarantee the image is genuine.
