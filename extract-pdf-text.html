Extract PDF Text - Copy the Text Out of Any PDF

Need the words out of a PDF, to quote them, edit them or feed them into something else? This extractor reads the PDF's text layer page by page and shows it cleanly, ready to copy or download as a .txt file.

Free · No sign-up · Works on phone and computerOpen the tool full-screen →

About this tool

Most PDFs created from Word, Google Docs or a website carry a hidden text layer, the actual words, separate from how the page looks. This tool reads that layer with pdf.js, page by page, and lays the text out with clear page breaks so you can see where everything came from. Copy a page, copy it all, or download the whole thing as a plain .txt file.

One honest warning, shown loudly rather than hidden: a PDF made by scanning paper is just a photograph of text. It has no text layer, so there is nothing to extract, and this tool flags those pages with a clear “no text layer” message instead of returning a confusing blank. For scanned pages, turn them into images with the PDF to Image tool and run them through Image to Text (OCR).

How to use it

  1. Choose your PDF, pick the file from your device; it is read in your browser only.
  2. Read the extraction, the text appears page by page, with a heading and break for every page.
  3. Watch for flagged pages, a page with no text layer (a scanned image) gets a clear message explaining why it is empty.
  4. Copy or download, copy all the text in one click, or download it as a .txt file.

What you get

  • Page-by-page layout, page headings and breaks keep long documents readable and quotable.
  • Copy or .txt download, one click either way, with page markers in the downloaded file.
  • Honest scanned-page detection, pages with no text layer are flagged clearly, never silently blank.
  • No uploads, pdf.js extracts the text on your device; the file never leaves it.

Frequently asked questions

How do I extract the text from a PDF?
Choose your PDF in the extractor above. The text layer of every page is extracted and shown page by page; copy it or download it all as a .txt file.
Why does a page say it has no text layer?
That page is a scanned image, a photograph of text rather than real, embedded text, so there is no text layer to extract. Convert the page to an image with the PDF to Image tool, then use the Image to Text (OCR) tool to read the words from the picture.
Will the formatting be kept?
You get clean plain text, in reading order, with page breaks, ideal for copying, quoting, editing and searching. Fonts, columns and exact layout are not preserved; for that, open the PDF itself.
Is my PDF uploaded anywhere?
No. pdf.js reads the file entirely in your browser, on your device.
